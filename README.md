## Features

- Premium, card-based recipe layout with soft shadows and rounded corners
- Responsive design for mobile, tablet, and desktop screens
- Ingredient checklist with accessible form controls
- Numbered cooking steps for quick scanning
- Interactive Cooking Mode with step-by-step navigation, timer, progress bar, and sound/flash alerts
- Clean, semantic markup with strong accessibility practices
- Modern typography and polished color system

## Tech Stack

- HTML5
- CSS3
- Google Fonts
- Unsplash imagery

## Setup and Installation

1. Clone or download the project folder.
2. Open the project in a browser directly, or run a local static server from the project directory.
3. If you want to serve it locally:

```bash
cd recipe-card
python -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.
